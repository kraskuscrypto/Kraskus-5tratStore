About MystNodes by Kraskus

This app manages the 5tratumOS packaging and onboarding experience while the node runtime remains the official upstream Mysterium Network software.

Persistent IdentityYour node identity remains stored in persistent app data across container recreation and updates.
Passive BandwidthShare eligible unused bandwidth through the MystNodes network and monitor activity in the official Node UI.
Residential NetworkParticipate in Mysterium's decentralized residential bandwidth network.
One-Click LaunchOpen setup from the 5tratumOS interface without SSH.
Official ContainerThe node service uses Mysterium Network's official pinned container image.
Kraskus OnboardingNew and existing MystNodes users get separate setup paths.
Referral disclosure: the New User button opens a Kraskus MystNodes referral link. Existing users can skip account creation. Referral attribution and rewards are controlled by MystNodes.
