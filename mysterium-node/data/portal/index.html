Network Setup & NAT
Open NAT provides the best peer connectivity.

Recommended Router / Firewall Settings

Node UI TCP 4449
Peer traffic UDP 56000–56100
Local Node UI http://NODE-IP:4449

NAT Status

Open Best connectivity
Moderate Usually works
Strict / Symmetric Limited connections
Recommended: assign the 5tratumOS host a stable LAN IP before creating port-forwarding rules. Enable UPnP or forward the required UDP range; avoid using UPnP, manual forwarding, and DMZ at the same time. TCP 4449 is the Node UI port and only needs internet exposure if you intentionally want remote Node UI access. Restart the MystNodes service after router or firewall changes, then allow several minutes for NAT status to update.
